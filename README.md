# LLM UI Benchmark

面向大语言模型（LLM）前端 UI/网页单页生成能力的综合对比评测基准与交互式效果预览工作台。

> 体验在线展示控制台：直接在浏览器中打开 `index.html`，即可无缝切换不同大模型在各个业务场景下的前端交互与视觉实现效果。

---

## 💡 评测理念升级：v2 开放自主设计

原先评测采用的提示词（v1）过于精细化地规定了具体模块、卡片结构和功能细节，限制了模型自身对业务场景的设计思考。

从 **v2** 开始，全面调整为**场景级开放设计提示词**：
- **不设预定义模板**：避免套用千篇一律的 Hero + 卡片网格 + Logo 墙，鼓励模型自主探索工作区结构与视觉记忆点；
- **重视设计语言与语境**：要求具备人文气息、有辨识度的排版、纸张感/纹理/微交互等高级网页特性，让视觉语言贯穿全页；
- **全内联纯原生交付**：单文件自包含 HTML/CSS/JS，所有代码与视觉资产（SVG/Canvas/WebGL）内联生成，不依赖外部 CDN/图片，确保评测环境一致与长期可复现。

*注：历史 v1 的精细提示词与早期生成效果已完整归档在系统中，可随时在工作台内一键切换对比。*

## 📋 评测场景提示词

### 1. 官网落地页 (Landing Page)
> 设计并实现一个品牌官网落地页。自行定义一个可信、有具体文化语境的品牌、产品或机构，不要复用常见 AI 产品叙事。页面要有人文气息，采用大胆、有辨识度的排版；克制但反复地运用纹理、纸张感、颗粒、遮罩、混合模式或其他高级网页特性，让它们形成贯穿页面的视觉语言，而不是一次性装饰。避免模板化的 Hero + 卡片网格 + Logo 墙结构。内容、节奏、空间和精致动效应共同构成完整叙事。所有视觉资产内联生成，不引用外部图片、字体或 CDN。

### 2. 复杂后台 (Complex Dashboard)
> 设计并实现一个复杂业务后台。自行选择一个确实需要高密度信息和多步骤判断的业务场景，建立清晰、可信的数据关系与任务流。页面必须自然包含可排序或筛选的数据表、可真实操作的表单、至少两种有意义的图表，以及状态、筛选或选中对象之间的联动；使用内置模拟数据完成有效交互。不要停留在通用侧栏、指标卡和占位图表组成的后台模板，应根据业务对象选择有设计感且高效的工作区结构。所有代码与视觉资产内联，不引用外部库、图片、字体或 CDN。

### 3. 通用 Agent (General Agent)
> 设计并实现一个通用智能体产品页面，包含话题或会话入口、主要对话区、输入与智能体状态。整体极简、克制、安静，但在排版、比例、留白、材质和微交互中藏有明确的设计判断。最重要的视觉记忆点是一个令人惊艳、具有生命感的拟人形象；它不必是真人，可以是智能体、动物、器物或抽象生命，并应通过内联 SVG、CSS、Canvas 或 WebGL 形成细腻的状态变化，而不是普通头像或发光圆球。避免常见三栏 AI 聊天模板和大面积渐变光晕。所有代码与视觉资产内联，不引用外部图片、字体或 CDN。

## 🚀 快速上手与使用

1. **直接预览**：
   通过任意本地静态文件服务器或双击 `index.html` 即可运行：
   ```bash
   npx serve .
   # 或
   python3 -m http.server 3000
   ```
2. **新增模型生成效果**：
   将模型按照提示词生成的单文件 HTML 放入 `results/v2/{model-id}/{template-id}/index.html`，刷新工作台即可自动侦测并展示，未生成时会友好显示占位提示。
